Node.js

Learn the fundamentals of Node.js, including modules, npm, servers, APIs and backend development.

Node.js Notes

What is Node.js?

Node.js is a JavaScript runtime environment that allows JavaScript to run outside the browser. It is commonly used for backend and server-side development.

Why is Node.js used?

Node.js is used to build web servers, REST APIs, real-time applications and backend services using JavaScript.

Node.js Modules

Modules are reusable pieces of code. Node.js provides built-in modules and also allows developers to create their own modules. 


const fs = require("fs");

const data = fs.readFileSync("example.txt", "utf8");

console.log(data);

npm

npm stands for Node Package Manager. It is used to install, manage and share JavaScript packages for Node.js projects. 


npm init -y

npm install express

Creating a Server

Node.js provides the HTTP module that can be used to create a basic web server. 


const http = require("http");

const server = http.createServer((req, res) => {
    res.write("Hello from Node.js!");
    res.end();
});

server.listen(5000, () => {
    console.log("Server running on port 5000");
});

Express.js

Express.js is a popular Node.js framework used to create web servers and APIs more easily. 


const express = require("express");

const app = express();

app.get("/", (req, res) => {
    res.send("Hello World!");
});

app.listen(5000, () => {
    console.log("Server running on port 5000");
});

REST API

A REST API allows applications to communicate through HTTP requests such as GET, POST, PUT and DELETE. 


app.get("/users", (req, res) => {
    res.json([
        { name: "Azhar" },
        { name: "Developer" }
    ]);
});

Middleware

Middleware functions run during the request-response cycle. They can be used for logging, authentication, validation and other backend tasks. 


app.use(express.json());

Environment Variables

Environment variables are used to store configuration values such as API keys, database URLs and port numbers. Sensitive values should not be committed to GitHub. 


const PORT = process.env.PORT || 5000;

app.listen(PORT, () => {
    console.log(`Server running on port ${PORT}`);
});

Simple Example


const express = require("express");

const app = express();

app.get("/", (req, res) => {
    res.json({
        message: "Node.js API is working!"
    });
});

app.listen(5000, () => {
    console.log("Server running on port 5000");
});
