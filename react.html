React Notes

What is React?

React is a JavaScript library used to build interactive and reusable user interfaces. It is commonly used for modern frontend web applications.

Why is React used?

React helps developers create reusable components, manage application state and build dynamic user interfaces efficiently.

Components

Components are reusable building blocks of a React application. A component can contain its own structure, logic and styling. 


function Welcome() {
    return <h1>Hello, Azhar!</h1>;
}

JSX

JSX is a syntax extension for JavaScript that allows developers to write HTML-like code inside JavaScript. 


const element = <h1>Hello World</h1>;

Props

Props are used to pass data from one component to another. They allow components to receive information from their parent component. 


function User({ name }) {
    return <h2>Hello {name}</h2>;
}

function App() {
    return <User name="Azhar" />;
}

State

State is data managed inside a React component. When state changes, React can update the user interface. 


import { useState } from "react";

function Counter() {
    const [count, setCount] = useState(0);

    return (
        <button onClick={() => setCount(count + 1)}>
            Count: {count}
        </button>
    );
}

Events

React supports events such as clicks, keyboard input and form submission. Event handlers are used to respond to user actions. 


function Button() {
    function handleClick() {
        alert("Button clicked!");
    }

    return <button onClick={handleClick}>Click Me</button>;
}

Conditional Rendering

Conditional rendering allows React to display different content depending on a condition. 


function Message({ isLoggedIn }) {
    return (
        <div>
            {isLoggedIn ? "Welcome!" : "Please log in."}
        </div>
    );
}

Lists and Keys

React can render lists using JavaScript array methods. Keys help React identify individual elements in a list. 


const skills = ["HTML5", "CSS3", "JavaScript"];

function Skills() {
    return (
        <ul>
            {skills.map((skill) => (
                <li key={skill}>{skill}</li>
            ))}
        </ul>
    );
}

Simple Example


import { useState } from "react";

function App() {
    const [message, setMessage] = useState("Hello");

    return (
        <div>
            <h1>{message}</h1>

            <button onClick={() => setMessage("React is working!")}>
                Click Me
            </button>
        </div>
    );
}

export default App;
