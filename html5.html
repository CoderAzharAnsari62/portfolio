HTML5 – Short Notes

What is HTML5?

HTML5 is the modern standard of HTML used to create the structure of web pages. It tells the browser how headings, paragraphs, images, links and other elements should be arranged.

Why is HTML5 used?

HTML5 is used to create the basic structure of a website. It allows developers to add text, images, links, lists, tables, forms, audio and video.

Basic HTML Structure

A basic HTML document mainly contains <html>, <head> and <body> elements.

Semantic HTML

Semantic HTML uses meaningful elements such as <header>, <nav>, <main>, <section> and <footer> to clearly describe the purpose of content.

Forms

HTML forms are used to collect information from users, such as names, email addresses, passwords and feedback.

Audio & Video

HTML5 provides <audio> and <video> elements for adding media directly to web pages.

Accessibility & SEO

Semantic HTML, meaningful headings and descriptive alt text can help improve accessibility and SEO.

Simple Example

<h1>My Portfolio</h1>

This code displays "My Portfolio" as a main heading on the web page.
