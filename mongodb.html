MongoDB

Learn the fundamentals of MongoDB, including databases, collections, documents, CRUD operations and data handling.

MongoDB Notes

What is MongoDB?

MongoDB is a NoSQL database that stores data in flexible document-oriented structures. It is commonly used in modern web applications.

Why is MongoDB used?

MongoDB is used for storing, managing and retrieving application data. Its flexible document structure makes it useful for applications with changing data models.

Database

A MongoDB database contains collections. A database can store the data required by an application. 


use myDatabase

Collections

A collection is a group of MongoDB documents. It is similar to a table in a relational database, but its documents can have flexible structures. 


db.users

Documents

MongoDB stores individual records as documents. Documents use a JSON-like format called BSON internally. 


{
    name: "Azhar",
    role: "Developer",
    age: 21
}

Insert Data

The insertOne() method can be used to add a single document to a collection. 


db.users.insertOne({
    name: "Azhar",
    role: "Developer"
})

Find Data

The find() method is used to retrieve documents from a collection. 


db.users.find()

Update Data

The updateOne() method can be used to modify an existing document. 


db.users.updateOne(
    { name: "Azhar" },
    { $set: { role: "Full Stack Developer" } }
)

Delete Data

The deleteOne() method can be used to remove a document from a collection. 


db.users.deleteOne({
    name: "Azhar"
})

CRUD Operations

CRUD stands for Create, Read, Update and Delete. These are the basic operations used to manage data in MongoDB. 


Create  → insertOne()
Read    → find()
Update  → updateOne()
Delete  → deleteOne()

MongoDB with Node.js

MongoDB can be connected to a Node.js backend using MongoDB drivers or libraries such as Mongoose. 


const mongoose = require("mongoose");

mongoose.connect(process.env.MONGODB_URI)
    .then(() => {
        console.log("MongoDB connected");
    })
    .catch((error) => {
        console.error(error);
    });

Simple Example


const mongoose = require("mongoose");

mongoose.connect(process.env.MONGODB_URI);

const User = mongoose.model("User", {
    name: String,
    role: String
});

const user = new User({
    name: "Azhar",
    role: "Developer"
});

user.save()
    .then(() => {
        console.log("User saved");
    });
