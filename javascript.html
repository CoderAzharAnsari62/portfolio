JavaScript Notes

What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic. It can respond to user actions, update content, handle events and communicate with web APIs.

Why is JavaScript used?

JavaScript is used to create interactive websites, validate forms, manipulate page content, handle user events, create animations and build modern web applications.

Variables

Variables are used to store data. JavaScript provides let, const and var for declaring variables. 


let name = "Azhar";
const age = 21;

Data Types

Common JavaScript data types include String, Number, Boolean, Undefined, Null, Object and BigInt. 


let name = "Azhar";
let age = 21;
let isStudent = true;

Functions

Functions are reusable blocks of code designed to perform a specific task. 


function greet(name) {
    return "Hello " + name;
}

console.log(greet("Azhar"));

DOM Manipulation

The Document Object Model (DOM) allows JavaScript to access and modify HTML elements dynamically. 


document.getElementById("title").textContent =
    "Welcome to my website";

Events

Events allow JavaScript to respond to user actions such as clicks, keyboard input, mouse movement and form submission. 


button.addEventListener("click", function () {
    alert("Button clicked!");
});

Arrays

Arrays are used to store multiple values in a single variable. 


const skills = [
    "HTML5",
    "CSS3",
    "JavaScript"
];

console.log(skills[0]);

Objects

Objects store data in key-value pairs and are commonly used to represent real-world entities. 


const student = {
    name: "Azhar",
    age: 21,
    role: "B.Tech Student"
};

console.log(student.name);
