CSS3 – Short Notes

What is CSS3?

CSS3 is a styling language used to design and style web pages. It controls colors, fonts, spacing, layouts and animations.

Why is CSS3 used?

CSS3 is used to make web pages attractive, responsive and user-friendly.

CSS Selectors

Selectors are used to target HTML elements so that styles can be applied to them. Common selectors include element, class and ID selectors.

Box Model

The CSS box model consists of content, padding, border and margin. It controls the size and spacing of elements.

Flexbox & Grid

Flexbox and Grid are modern CSS layout systems used to arrange elements efficiently and create flexible page layouts.

Responsive Design

Responsive design allows a website to adapt properly to different screen sizes such as mobile, tablet and desktop.

Animations & Transitions

CSS animations and transitions can be used to create smooth visual effects when elements change their appearance or position.

Simple Example

color: gold;
font-size: 18px;

These CSS properties change the text color and font size of an element.
